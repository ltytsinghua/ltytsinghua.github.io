## 1. 想法

作为一名理论物理工作者，我由衷地感到，今天的 AI 在数学推导和编程上的能力，在很多方面已经超过了人类。但在理论物理里，最重要的工作往往不是复杂的计算和推导，而是**理解实验现象，建立一套能和实验沟通的语言**。好的物理工作，常常用简单清楚的理论就抓住了实验的核心现象。

唯象理论在很大程度上是理论和实验之间的接口，而且它的构建流程和推导相对系统：从对称性出发确定序参量，写出自由能，再推出可观测量。凝聚态中的 Ginzburg–Landau（GL）理论就是典型的例子。

所以我想以它为切入点，**让 AI 学会用这套语言，以简单清楚的方式描述实验系统中的现象，并做出可以检验的实验预言。**

## 2. 唯象研究的工作流

1. **读实验**：从比热、超声、Raman、NMR、μSR、输运等数据中提取关键信号。
2. **定序参量**：破缺了哪些对称性，序参量属于高对称群的哪个不可约表示。
3. **写自由能**：列出对称性允许的不变量，包括梯度项以及与应变、磁场、其他序的耦合。
4. **求极小**：得到基态、相图，判断相变级次。
5. **算可观测量**：比热跳变、弹性常数异常、$$H_{c2}$$ 各向异性、集体模……
6. **对比与修正**：和实验不符就回到第 2 步。

第 4、5 步是 AI 已经擅长的。第 1 步需要人类经验和数值工具配合，下面单独展开。第 2、3、6 步是另一个瓶颈：选错表示、漏掉不变量、搞错时间反演性质、过早认定一个模型。好在这些步骤**大多可以用群论和符号计算工具严格检验**。

### 2.1 读实验

实验数据本身不会告诉你哪些特征重要。这一步需要两样东西配合：**人类积累的经验**，告诉 AI 该看什么；**编程和数值手段**，把信号可靠地提取出来。

**常见的实验信号及其含义**

| 实验信号 | 通常意味着 |
|---|---|
| 比热在 $$T_c$$ 处跳变 | 二级相变；跳变大小 $$\Delta C/\gamma T_c$$ 可与平均场或 BCS 值（约 1.43）比较 |
| 零场下出现两个比热跳变 | 两个相继的相变，常提示多分量序参量（如 UPt₃） |
| 升降温曲线有回滞 | 一级相变 |
| 剪切模量（如 $$c_{66}$$）在 $$T_c$$ 处跳变 | 序参量的双线性组合能和剪切应变耦合，常提示多分量序参量 |
| 弹性常数在相变上方持续软化 | 与应变耦合的序参量涨落，如向列相变 |
| 四方晶格中，输运或磁化的角度依赖出现二重分量 | 旋转对称性破缺（向列序） |
| 零场 μSR 弛豫率增加、极化 Kerr 信号 | 时间反演对称性破缺 |
| NMR Knight shift 在 $$T_c$$ 以下是否下降 | 区分自旋单态与自旋三重态配对 |
| 一个相变在应变或磁场下分裂成两个 | 原本简并的多分量序参量被外场劈裂 |
| 临界区的幂律行为 | 平均场是否适用，属于哪个普适类 |

**用数值手段提取信号**

只靠看图不够可靠，小信号和定量结论尤其如此。每类特征都可以对应一个提取程序：

- **扣除背景**：比热中的声子贡献、电阻的本底等。尝试不同的扣除方式，检验结论是否稳健。
- **定位相变**：用导数、峰值，或比热的等熵构造，确定 $$T_c$$ 和跳变大小。
- **判断级次**：对比升温和降温数据，看是否有回滞。
- **拟合幂律**：在双对数坐标下拟合，扫描拟合区间，给出指数及其不确定度。
- **分析角度依赖**：对角度扫描数据做 Fourier 分解，比较各重对称分量的大小。
- **跟踪相图**：记录相变点随温度、磁场、应变的变化，找出分裂、汇合和 kink。

**仍需人类提供的**

- **实验条件**：测的是什么量；磁场、电流、应变沿什么方向；样品是什么。
- **对假象的判断**：样品不均匀、杂相、仪器问题都可能造成假信号，这一步很依赖实验经验。

提取的结果整理成结构化的特征报告（见第 3 节），作为下一步建立理论的输入。

## 3. 方案

**先做 agent，再用 agent 的轨迹构造数据集。**

- **工具**：群论（不可约表示分解、不变量生成，如 Bilbao、ISOTROPY）、符号计算、数值求极小和解 GL 方程、数据拟合、文献检索。
- **多假设并行**：同时保留几个候选序参量，用实验逐个排除，而不是一开始就认定一个。
- **特征报告作为中间层**：原始数据曲线先经过特征提取（跳变、回滞、幂律、谐波分量……），整理成结构化的特征报告，再交给 GL 推理模块。AI 读不好的曲线可以由人直接写报告，接口不变；两个模块也能分开评测。
- **分层数据集**：

| 层级 | 任务 | 验证方式 |
|---|---|---|
| L1 | 给定点群和表示，列出不变量 | 群论软件自动验证 |
| L2 | 给定自由能，求基态、相图、可观测量 | 符号或数值自动验证 |
| L3 | 给定实验特征，判断允许或排除哪些表示 | 大部分可自动验证 |
| L4 | 从实验到完整理论和预言 | 专家按评分细则打分 |
